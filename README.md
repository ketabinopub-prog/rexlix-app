# rexlix – اپ اندروید (WebView)

۱. همه‌ی فایل‌ها را در یک ریپازیتوری GitHub آپلود کنید (شاخه main).
۲. تب **Actions** → workflow با نام **Build APK** اجرا می‌شود (یا Run workflow بزنید).
۳. بعد از چند دقیقه، در پایین صفحه‌ی اجرا، بخش **Artifacts** فایل `rexlix-apk` را دانلود کنید (zip است؛ داخلش `app-release.apk`).

## شخصی‌سازی
- آدرس سایت: `MainActivity.kt` → `START_URL`
- رنگ برند: `app/src/main/res/values/colors.xml`
- آیکون: `res/drawable/ic_launcher_foreground.xml` و `res/mipmap-anydpi-v26/`
